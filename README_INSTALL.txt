ACOUSTIC GUITAR BY JGK V6 - WINDOWS
====================================

1. Extract the GitHub Actions artifact ZIP.
2. Double-click INSTALL_PLUGIN.bat.
3. Approve the Windows administrator prompt.
4. Open FL Studio.
5. Options > Manage plugins > Find installed plugins.
6. Load "Acoustic Guitar by JGK".

The VST3 is copied to:
C:\Program Files\Common Files\VST3\Acoustic Guitar by JGK.vst3

V6 uses embedded CC0 recordings from a 2017 Martin HD28 Vintage Series as its
main tone and shapes them toward a tighter contemporary singer-songwriter sound.
No separate sample folder is required after the plugin is built.
