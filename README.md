# Acoustic Guitar by JGK V6

Upload the contents of this folder directly to the root of an empty GitHub repo.
GitHub Actions will automatically build the Windows VST3.

## After upload
1. Open the repo's **Actions** tab.
2. Open **Build Acoustic Guitar by JGK V6**.
3. Wait for the green tick.
4. Open the finished run.
5. Under **Artifacts**, download **Acoustic-Guitar-by-JGK-V6-Windows**.
6. Extract it and run **INSTALL_PLUGIN.bat**.

No local JUCE, Visual Studio, or CMake setup is required for normal use.

## V6 features
- Real embedded CC0 acoustic-guitar recordings as the main tone
- Chord root + chord type selection
- Major, minor, 7, maj7, min7, sus2, sus4, add9
- Capo 0-12
- Down/up strumming
- 8 built-in rhythm patterns
- Humanize, palm mute, dynamics, tone, room and output
- Manual MIDI mode
- Original Acoustic Guitar by JGK visual skin
